# Claude Code Guardrails

Claude Codeの事故を、起きる前に機械で止めるフックの詰め合わせです。

AIに開発を任せていると、たまに取り返しのつかないことが起きます。`.env` の中身が会話のログへ残る、`git reset --hard` でコミットしていない変更が消える、`gh auth token` の出力がそのまま画面に出る。どれも「気をつける」では防げません。**注意力で防ぐのをやめて、機械に止めさせます。**

## 何を止めるか

| フック | 止めるもの |
|---|---|
| `block_secret_file_access.py` | `.env`・`id_rsa`・`credentials.json` などの読み書き |
| `block_secret_dump_commands.py` | `gh auth token`・`stripe config --list` など、秘密を画面へ出すコマンド |
| `block_destructive_commands.py` | `rm -rf /`・`git reset --hard`・`git push --force`・`DROP TABLE` など |

## 使ってみる

```bash
git clone https://github.com/akkylab/claude-code-guardrails.git
cd claude-code-guardrails
./install.py --dry-run   # 何が変わるかを見る
./install.py             # 組み込む
```

Claude Codeを起動し直すと効き始めます。外すときは `./install.py --uninstall` です。

`~/.claude/settings.json` は書き換える前に `settings.json.guardrails-backup` へ退避します。あなたが自分で入れたフックには手を触れません。

Pythonの標準ライブラリだけで動くので、追加の依存はありません。

## 止まると、どう見えるか

```
元に戻せない操作を実行しようとしています。

  何が起きるか: コミットしていない変更が、元に戻せない形で消えます
  代わりにどうするか: 先に `git stash` で退避するか、`git status` で失うものを確認してください

本当にこの操作が要る場合は、環境変数を付けて1回だけ通してください。

  GUARDRAILS_ALLOW_DESTRUCTIVE=1 <もとのコマンド>
```

**止める理由だけでなく、代わりに何をすればよいかを必ず返します。** 理由だけを返すと、Claude Codeは同じことを別の書き方で試そうとします。進む道を示すほうが、結果として安全になります。

## 逃げ道を用意しています

意図して実行したい場面は必ずあります。そのときは環境変数を付けてください。

| 環境変数 | 効果 |
|---|---|
| `GUARDRAILS_ALLOW_SECRET_FILES=1` | 秘密のファイルの判定を止めます |
| `GUARDRAILS_ALLOW_SECRET_DUMP=1` | 秘密を吐くコマンドの判定を止めます |
| `GUARDRAILS_ALLOW_DESTRUCTIVE=1` | 元に戻せない操作の判定を止めます |

逃げ道を塞がないのは、外されないためです。**誤って止めるフックは、邪魔だと感じた時点で丸ごと外されます。**外されたら何も守れません。1回だけ通す道を残しておくほうが、結果として長く守れます。

## 設計で気をつけていること

### 入力の中身をログに書きません

フックが受け取るのはコマンドの文字列です。次のような実行をすれば、秘密が確実に記録されます。

```
curl -H "Authorization: Bearer <トークン>" https://api.example.com
```

そこで共通部品の `read_hook_input` は、ロガーを引数に取れない形にしてあります。呼び出す側が書こうとしても、書ける口がありません。各フックは判定の結果だけを記録します。

### ログが書けなくても判定を止めません

ログは後から様子を見るためのものです。書けないことを理由にツールの実行を止めると、あなたの作業が巻き添えになります。置き場を作れないときは、何もしないロガーで先へ進みます。

### 壊れた入力で警告を出しません

入力がJSONとして読めないとき、フックが落ちると終了コード1が返り、ハーネスは毎回警告を出します。止まりはしませんが、その警告が「外す理由」になります。壊れた入力は静かに通します。

### 雛形は止めません

`.env.example`・`.env.template`・`.env.sample` は値ではなく書き方の見本です。これを止めると、新しく参加した人が設定の書き方を読めなくなります。

## テスト

```bash
python3 -m pytest tests/ -q
```

52件あります。内訳は「止めるべきものが止まること」と「通すべきものが通ること」がほぼ同数です。

後者を軽く見ていません。`git branch -D`（未マージでも消す）を止める規則が、大文字小文字を無視していたせいで安全な `git branch -d` まで止めていた不具合は、このテストが見つけました。
