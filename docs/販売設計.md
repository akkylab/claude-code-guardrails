# 販売設計

このリポジトリをどう売って、いくら得るかの設計です。akkyから売り方を任されたので、判断とその理由をここへ残します。

## 最初に、都合の悪い事実を書きます

**コードそのものは売りにくいです。**

このリポジトリの中身は、Pythonのスクリプトが数本です。MITライセンスで公開すれば誰でもコピーできますし、公開しなくても、同じものを作れる人はいます。「秘密のファイルを止める」という発想自体に独占できる要素がありません。

ですから「フックを売る」という組み立てだと、たぶん売れません。ここを曖昧にしたまま出品ページを作っても、時間を捨てるだけです。

## では何が売れるか

売れるのは、コードではなく**そこへ至るまでの時間**です。

```
   買う人が払っているもの
   ┌────────────────────────────────────────────────┐
   │ ✗ Pythonのスクリプト数本                        │
   │                                                │
   │ ○ 「何を止めるべきか」を自分で洗い出す時間      │
   │ ○ 事故を実際に起こして学ぶ授業料                │
   │ ○ 誤って止めて作業が詰まる試行錯誤              │
   └────────────────────────────────────────────────┘
```

この3つは、コードを読んでも手に入りません。`docs/守れない範囲.md` のような「どこまでしか守れないか」の整理や、「誤って止めるフックは外される」という設計判断のほうが、スクリプト本体より価値があります。

## 3段構えにします

```
   第1段  GitHubで公開（無料）
          コアの3本 + README + 守れない範囲
            │  認知を取る。ここでは1円も取りません
            ▼
   第2段  noteの有料記事（1,500円）
          Claude Codeを複数並列で運用するときの事故と、その塞ぎ方
            │  コードでは伝わらない部分。ここが本命です
            ▼
   第3段  BOOTH（3,000円）
          全フック + 導入ランブック + 設定の雛形
```

### なぜ無料の段を置くか

**誰も知らないものは売れません。**まず使ってもらい、「これは効く」と分かってもらう必要があります。

MacWhisperの開発者（Jordi Bruin氏）は、広告費をかけず、開発者本人の発信と製品の継続的な改善で30万本を売りました。同じ道筋を採ります。無料の段は宣伝費の代わりです。

### なぜnoteが本命か

第2段だけが、他の人に真似できません。

akkyは複数のClaude Codeを並列で動かし、フックで事故を機械的に止め、ランブックで運用を回しています。**同じことを実際にやっている人は国内にほとんどいません。**そこで起きた具体的な事故と、それをどう塞いだかは、体験した人しか書けません。

第1段と第3段はコードなので真似されます。第2段は真似されません。

### なぜBOOTHか

日本語で個人がデジタル商品を売る場として定着しており、審査が軽く、始めるまでが速いためです。Adobe Exchangeのような重い審査を待つ理由がありません。

## いくらになるか

正直に見積もります。**これで生活は変わりません。**

| 段 | 単価 | 月に出る数の見込み | 月の売上 |
|---|---|---|---|
| 第1段 | 0円 | ─ | 0円 |
| 第2段 | 1,500円 | 3〜10件 | 4,500〜1万5,000円 |
| 第3段 | 3,000円 | 1〜3件 | 3,000〜9,000円 |

合計で月7,500円〜2万4,000円というあたりです。akkyの目標（月1万円でも構わない）には届きますが、それ以上ではありません。

見込みの根拠が薄いことも書いておきます。**この数字は、同種の商品の実売データを見て出したものではありません。**出品したあとに実測して、この表を書き換えます。

## 公開の判断は、まだしていません

このリポジトリはプライベートのままにしてあります。**公開は取り消せないためです。**一度公開したものは、消してもコピーが残ります。

公開する前に、次を確認します。

- [ ] akky固有の情報（実名・メール・プロジェクト名・パス）が1つも残っていないこと
- [ ] `~/.claude` の実ファイルを取り込んでいないこと
- [ ] akkyの承認を得ること

いまの中身はゼロから書き起こしたもので、既存のフックをコピーしていません。ですが、確認せずに公開はしません。

## 次にやること

1. akkyへ設計を報告し、公開してよいかの判断を仰ぐ
2. 承認が出たら公開し、READMEを整える
3. noteの記事を書く（ここが本命なので、いちばん時間をかける）
4. BOOTHへ出品する
5. 1か月後に実売を測り、この文書の見込みの表を実測値へ書き換える

5番を飛ばさないでください。**見込みのまま置いておくと、当たったのか外れたのか誰にも分からなくなります。**
